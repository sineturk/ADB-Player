# ADB Player Support

## User support

For ADB Player account, privacy or cloud-data requests, use one of these private routes:

- Email: **destek@altyazidb.com**
- Contact form: **https://altyazidb.com/index.php?do=feedback**

Do not include passwords, access tokens, API keys, OAuth secrets or other credentials in support messages.

## GitHub issues

Public GitHub issues are appropriate for reproducible application bugs and public feature requests. Before reporting a bug, include the ADB Player version, Windows version, reproduction steps and only the non-sensitive log lines needed to diagnose the problem.

Do **not** use a public issue for account deletion, private account details, security reports or secrets.

## Security reports

For suspected security vulnerabilities, follow [SECURITY.md](SECURITY.md).
