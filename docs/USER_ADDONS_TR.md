# Eklentiler

Eklentiler sekmesi yalnız kullanıcının kendi sağladığı kurulum adreslerini kabul eder. Uygulamayla birlikte herhangi bir eklenti listesi veya varsayılan adres gelmez.

1. Medya Merkezi > Eklentiler bölümünü açın.
2. Eklenti adresini girin.
3. Yerel bir servis HTTP kullanıyorsa yerel ağ iznini açın.
4. İki kullanıcı onayını işaretleyin.
5. **Eklentiyi ekle** düğmesine basın.

Eklenti yalnız oynatma kaynağı sağlıyorsa içerik kartları için ayrıca katalog sağlayan, yine kullanıcı tarafından eklenmiş bir eklenti gerekir.
